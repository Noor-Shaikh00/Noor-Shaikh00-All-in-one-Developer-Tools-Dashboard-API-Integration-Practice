# 🛠️ Developer Tools Hub

**All-in-one Developer Tools Hub:** JSON Formatter, Crypto & Stock Tracker, IP Lookup with Dark/Light Mode & Favorites sidebar.  
Professional dashboard for developers to test APIs and tools in one place.

---

## Features

- 🌙 **Dark / Light Mode Toggle** – Switch themes instantly  
- 📊 **JSON Formatter** – Paste JSON and get it formatted neatly  
- 💰 **Crypto Tracker** – Check live crypto prices (bitcoin, ethereum, etc.)  
- 📈 **Stock Tracker** – Track stock prices (TSLA, AAPL, etc.) using Yahoo Finance  
- 🌐 **IP Lookup** – Check IP details (country, city, ISP, coordinates)  
- ⭐ **Favorites Sidebar** – Save your frequently used tools  
- 🔎 **Search Bar** – Quickly filter and find the tool you need  
- ✅ Fully responsive and portfolio-ready design
